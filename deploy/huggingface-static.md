# Guardian 银盾陪护

连续对话中的危险动作提醒，包含老人端、分析台和本页家属确认演示。

这是免费静态网页版本：全部规则与序列决策在浏览器内运行，不包含真实电话监听、真实家属通知或在线模型代理。

完整源码、测试、参赛材料与 Docker 后端配置：[chendi-Shi/guardian-senior-safety](https://github.com/chendi-Shi/guardian-senior-safety)。GitHub 仓库当前为私有，需有访问权限。

本 Space 从源码仓库的 `node scripts/export-static.mjs` 生成。评估使用合成开发脚本，不代表真实防护效果。
