# Guardian 银盾陪护

在连续对话中的危险操作请求出现时提醒，面向老人的数字安全带黑客松原型。

## 现场演示

选择「冒充客服 · 取消保障」，点击「下一句」逐句回放。安装软件请求触发提醒，屏幕共享请求触发高危提醒；点击「请家人帮我确认」可体验本页模拟闭环。

另有冒充公检法、正常客服和反诈科普三个对照场景，支持手动输入、老人模式与分析记录导出。

## 当前边界

规则提取、对话序列图、风险更新和介入决策全部在浏览器内运行。风险分和预测权重是启发式结果，未用真实样本校准。未接入真实电话、实时语音转写、在线模型代理、支付拦截或真实家属通知。输入仅保留在当前页面内存中。

静态入口内嵌脚本与样式，没有外部运行依赖；不需要 API 密钥。

完整源码、27 项测试和参赛材料：[GitHub](https://github.com/chendi-Shi/guardian-senior-safety)（仓库当前为私有）。
