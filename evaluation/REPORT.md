# Guardian 合成场景评估

50 个公开开发脚本：20 条诈骗、20 条正常、10 条边界。当前规则参与了脚本设计，结果不能作为真实泛化性能。

|方法|诈骗场景主动提醒率|正常场景误扰率|边界误扰率|BHAR|命中场景平均提前时间|
|---|---:|---:|---:|---:|---:|
|关键词基线|100%|30%|80%|75%|8 秒|
|Guardian 规则＋序列|75%|0%|0%|75%|8 秒|

主动提醒定义为介入级别 ≥3。BHAR 只计针对目标危险动作、且发生在标注执行时刻之前的提醒。所有危险请求在脚本 48 秒，假定 56 秒执行，因此这里的提前 8 秒是脚本设定，不是测量出的防护效果。

LLM 单轮基线：未运行，不填成绩。阈值不由此数据集调优。

Guardian 未在执行前针对动作提醒的案例：euphemism-01、euphemism-02、euphemism-03、euphemism-04、euphemism-05。它们使用隐晦表达，展示规则提取的覆盖缺口。

复跑：`node scripts/evaluate.mjs`。原始逐例结果在 `evaluation/results.json`。
